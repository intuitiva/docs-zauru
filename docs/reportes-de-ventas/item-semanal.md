Si quiere seguir el ritmo de venta de un producto semana a semana, este reporte le muestra esa evolución de un vistazo. Solo elija el ítem o paquete y el periodo, y verá las cantidades vendidas en cada semana, lo que le sirve para notar cuándo un producto se acelera o se queda rezagado.

Para ingresar al reporte:

1. Hacer click en "Ventas".
2. Seleccionar "Reportes".
3. Seleccionar "Ítem Semanal".
4. Seleccionar el ítem o paquete y el periodo a consultar.

Con ese seguimiento semanal podrá notar las tendencias con anticipación y planificar sus compras o promociones con datos reales.

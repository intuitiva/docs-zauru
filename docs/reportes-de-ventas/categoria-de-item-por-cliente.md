Para conocer qué tipo de productos compra cada cliente y orientar su próxima oferta, este reporte le muestra el análisis de las categorías de ítems que cada cliente ha comprado.

Para ingresar al reporte:

1. Hacer click en "Ventas".
2. Seleccionar "Reportes".
3. Seleccionar "Categoría de Ítem por Cliente".

Con esa vista puede preparar promociones dirigidas y saber exactamente qué ofrecerle a cada cliente en su siguiente visita.

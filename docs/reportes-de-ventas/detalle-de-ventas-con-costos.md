title: "Detalle de Ventas con Costos"
sidebar_label: "Detalle de Ventas con Costos"
sidebar_position: 68
---

Cuando quiere saber cuánto le dejó realmente cada venta, este reporte le muestra el detalle de ventas con los costos, márgenes y rentabilidad de cada ítem.

Para ingresar al reporte:

1. Hacer click en "Ventas".
2. Seleccionar "Reportes".
3. Seleccionar "Detalle de Ventas con Costos".

Con esa información decide qué productos conviene impulsar y cuáles le están quitando margen.

Si quiere ver la utilidad del período sin pasar por cada línea de detalle, esta versión resumida es para usted. Le muestra las ventas con sus costos en cifras consolidadas, perfectas para una reunión rápida o un vistazo al cierre.

Para ingresar al reporte:

1. Hacer click en "Ventas".
2. Seleccionar "Reportes".
3. Seleccionar "Ventas con Costos (Resumen)".

Con estas cifras consolidadas puede responder en segundos cuánto se vendió y cuánto se ganó.

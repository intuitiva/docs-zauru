Antes de emitir la primera factura, este módulo define cómo se vende y cómo se cobra: los plazos de crédito, los descuentos, los métodos de pago y los precios que usarán las facturas. Todo se configura una sola vez en "Ventas" > "Configuraciones", y después cada venta se contabiliza y se cobra según lo definido aquí.

![imagen1](/img/ventas/configuraciones-1.jpg)

Las pestañas de configuración son las siguientes:

1. **[Términos de Pago](/ventas/configuraciones/terminos-de-pago)**: plazos y porcentajes de crédito, con las cuentas contables y categorías de clientes que aplican a cada término.
2. **[Descuentos](/ventas/configuraciones/descuentos)**: descuentos de monto fijo o porcentaje, aplicables a términos de pago, ítems, paquetes y categorías de clientes.
3. **[Métodos de Pago](/ventas/configuraciones/metodos-de-pago)**: formas de cobro (efectivo, tarjeta, depósito) y cuentas contables que se afectan al registrar cada pago.
4. **[Listados de Precios](/ventas/configuraciones/listados-de-precios)**: precios de venta distintos por categoría de cliente o punto de venta.
5. **[Tipos de Tarjeta de Regalo](/ventas/configuraciones/tarjetas-de-regalo)**: características de las tarjetas de regalo que se pueden emitir.
6. **[Configuraciones de Gateway](/ventas/configuraciones/configuraciones-de-gateway)**: integración con procesadores de pago para tokenizar tarjetas de crédito, procesar cobros y manejar reembolsos.
7. **[Operaciones de Gateway](/ventas/configuraciones/operaciones-de-gateway)**: bitácora de las interacciones con las pasarelas de pago, con filtro por estado y fecha.
8. **[Otras Configuraciones](/ventas/configuraciones/otras-configuraciones)**: variables de validación y comportamiento, webhooks, almacenamiento externo de documentos (FEL) y envío automático de correos.

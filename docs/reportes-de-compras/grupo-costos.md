Costo del inventario actual, por agencia, a una fecha y con método PEPS.

- **[Costo Inventario Actual](/reportes-de-compras/costo-inventario-actual)**: Muestra el costo unitario de cada producto del inventario.
- **[Costo de Inventario Actual por Agencia](/reportes-de-compras/costo-de-inventario-actual-por-agencia)**: Muestra el costo promedio de cada producto para una agencia específica.
- **[Costo de Inventario Actual (Método PEPS)](/reportes-de-compras/costo-de-inventario-actual-metodo-peps)**: Calcula el costo actual de cada producto con el método PEPS.
- **[Costo de Inventario a una Fecha](/reportes-de-compras/costo-de-inventario-a-una-fecha)**: Reconstruye el valor del inventario en una fecha pasada con los costos promedio registrados.
- **[Movimientos de Costo de Inventario](/reportes-de-compras/movimientos-de-costo-de-inventario)**: Muestra el saldo inicial, las entradas y salidas, y el saldo final del inventario en un período.
- **[Cierre Diario de Compras](/reportes-de-compras/cierre-diario-de-compras)**: Resume las órdenes de compra, los pagos y las anulaciones de un día, con totales por término de pago.

Volver a [Reportes de Compras](/reportes-de-compras).

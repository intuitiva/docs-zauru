title: "Item de Compra entre Fechas"
sidebar_label: "Item de Compra entre Fechas"
sidebar_position: 14
---

Si quiere seguir la pista de un producto específico, por ejemplo para ver cómo ha cambiado su precio, este reporte le muestra cada orden de compra que incluye ese producto entre dos fechas, con cantidades, costos unitarios originales y costos finales calculados. Es la forma más rápida de revisar el historial de compra de un solo producto.

Para ingresar al reporte:

1. Ir a "Compras".
2. Seleccionar "Reportes".
3. Seleccionar "Item de Compra entre Fechas".
4. Seleccionar el item y el rango de fechas.

Con este detalle tendrá a la mano el historial de precios del producto para comparar proveedores o revisar incrementos de costo.

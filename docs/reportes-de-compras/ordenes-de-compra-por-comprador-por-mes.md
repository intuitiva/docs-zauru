Cuando llega el fin de mes y quiere ver cuántas órdenes emitió cada comprador de su equipo, este reporte se las agrupa por persona. Le sirve para evaluar la carga de trabajo de cada comprador o para revisar mes a mes el desempeño del área de compras.

Para ingresar al reporte:

1. Ir a "Compras".
2. Seleccionar "Reportes".
3. Seleccionar "Ordenes de Compra por Comprador por Mes".
4. Seleccionar el mes y año.

Con esta foto mensual podrá reconocer el esfuerzo de cada comprador y balancear mejor la carga de trabajo del equipo.

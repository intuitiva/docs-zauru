Cuando necesita entender cómo cambió el valor de su inventario en un periodo, este reporte le da el panorama completo: el saldo con el que empezó la agencia, cada entrada y salida, y el saldo final. Es ideal para conciliar costos a fin de mes o para rastrear de dónde vino un movimiento de inventario que no le cuadra.

Para ingresar al reporte:

1. Ir a "Compras".
2. Seleccionar "Reportes".
3. Seleccionar "Movimientos de Costo de Inventario".
4. Seleccionar el rango de fechas y la agencia.

Con este reporte podrá revisar el historial de movimientos de una agencia y confirmar que los saldos finales cuadren con lo que tiene registrado.

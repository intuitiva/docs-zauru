Cuando el costo de un producto no le cuadra o necesita rastrear su historial completo, el kardex es su mejor aliado. Este reporte le muestra todas las entradas y salidas de un producto entre dos meses, con costos unitarios, costos promedio y saldos acumulados, para que pueda seguir el rastro de cada movimiento. Es una herramienta útil para auditorías de costos y trazabilidad de inventario.

Para ingresar al reporte:

1. Ir a "Compras".
2. Seleccionar "Reportes".
3. Seleccionar "Kardex de Producto entre Fechas".
4. Seleccionar el producto y el rango de fechas.

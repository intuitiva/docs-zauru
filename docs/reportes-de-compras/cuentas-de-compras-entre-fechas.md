title: "Cuentas de Compras entre Fechas"
sidebar_label: "Cuentas de Compras entre Fechas"
sidebar_position: 17
---

Si su empresa compra servicios o registra gastos por cuentas contables, como fletes o mantenimiento, este reporte le muestra en una matriz cada orden de compra con las cuentas contables que afecta. Es ideal para revisar de un vistazo en qué conceptos se concentra el gasto de un periodo.

Para ingresar al reporte:

1. Ir a "Compras".
2. Seleccionar "Reportes".
3. Seleccionar "Cuentas de Compras entre Fechas".
4. Seleccionar el rango de fechas.

Con esta matriz podrá ver rápidamente cuánto ha gastado en cada servicio o cuenta, sin abrir una a una las órdenes de compra.

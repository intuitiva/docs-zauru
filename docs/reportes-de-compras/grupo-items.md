Compras por producto, categoría, proveedor y orden, incluido el kardex.

- **[Productos Comprados a Proveedores entre Fechas](/reportes-de-compras/productos-comprados-a-proveedores-entre-fechas)**: Muestra las compras a cada proveedor producto por producto, con cantidades y costos.
- **[Productos Comprados entre Fechas](/reportes-de-compras/productos-comprados-entre-fechas)**: Resume las compras entre dos fechas por producto, con cantidad, costo promedio y costo total.
- **[Categorías de Productos Comprados entre Fechas](/reportes-de-compras/categorias-de-productos-comprados-entre-fechas)**: Agrupa las compras por categoría de producto entre dos fechas, con el costo total de cada una.
- **[Categorías de Productos Comprados por Agencia entre Fechas](/reportes-de-compras/categorias-de-productos-comprados-por-agencia-entre-fechas)**: Desglosa las compras por agencia y categoría entre dos fechas.
- **[Ítem de Compra entre Fechas](/reportes-de-compras/item-de-compra-entre-fechas)**: Lista las órdenes de compra que incluyen un producto específico entre dos fechas.
- **[Categoría de Ítem de Compra entre Fechas](/reportes-de-compras/categoria-de-item-de-compra-entre-fechas)**: Lista las órdenes de compra que incluyen productos de una categoría entre dos fechas.
- **[Ítems de Compras entre Fechas](/reportes-de-compras/items-de-compras-entre-fechas)**: Presenta una matriz de órdenes de compra por producto, con cantidades y costos.
- **[Órdenes de Compra entre Fechas](/reportes-de-compras/ordenes-de-compra-entre-fechas)**: Lista una por una las órdenes de compra emitidas en un período.
- **[Órdenes de Compra Sin Recibir](/reportes-de-compras/ordenes-de-compra-sin-recibir)**: Lista las órdenes autorizadas que aún no se han recibido.
- **[Órdenes de Compra Recibidas por Mes](/reportes-de-compras/ordenes-de-compra-recibidas-por-mes)**: Muestra las órdenes recibidas en un mes, con el detalle de lo que llegó.
- **[Kardex de Producto entre Fechas](/reportes-de-compras/kardex-de-producto-entre-fechas)**: Muestra todas las entradas y salidas de un producto entre dos meses, con costos.

Volver a [Reportes de Compras](/reportes-de-compras).

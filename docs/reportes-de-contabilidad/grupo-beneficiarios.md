- **[Movimientos de Beneficiario en Cuenta](/reportes-de-contabilidad/movimientos-de-beneficiario-en-cuenta)**: Muestra todas las transacciones de un beneficiario dentro de una cuenta, con su historial.
- **[Pagos Pendientes de un Beneficiario](/reportes-de-contabilidad/pagos-pendientes-de-un-beneficiario)**: Muestra las partidas no reconciliadas de un proveedor o cliente en una cuenta.

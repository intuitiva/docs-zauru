Este reporte muestra un balance corrido (tipo estado de cuenta) de todas las transacciones etiquetadas con un tag especifico. Es util para llevar el control financiero de un proyecto o area.

Para ingresar a este reporte:

1. Ir a "Contabilidad".
2. Seleccionar "Reportes".
3. Seleccionar "Balance Etiquetado".

**Parametros**:

- **Etiqueta**.

El libro de ventas diario nos muestra la información por día.

Se encuentra localizado en:

  - Contabilidad
  - Reportes
  - Libro de Ventas Diario

![Libro de ventas diario](/img/reportes-de-contabilidad/libro-de-ventas-diario-1.png)

**Parametros**:

- **Mes y año**: mes a reportar.
- **Agencia** (opcional): filtrar por agencia especifica.

Este reporte permite consultar el libro de ventas para un dia especifico o un rango de dias.

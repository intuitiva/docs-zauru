El libro de ventas consolidado es por día, respalda la venta de bienes y servicios que efectúa una empresa.

Los pasos para localizar el libro de ventas son:

  - Contabilidad
  - Reportes
  - Libro de Ventas consolidado

![Libro de ventas consolidado](/img/reportes-de-contabilidad/libro-de-ventas-consolidado-1.png)

El libro de ventas consolidado agrupa las facturas por serie de numeracion correlativa.

**Parametros**:

- **Mes y año**: mes a reportar.
- **Agencia** (opcional): filtrar por agencia especifica.

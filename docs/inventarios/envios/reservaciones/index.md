Una reservación es el primer paso de un envío: se reservan los productos en la bodega origen para que no se usen en otro movimiento, pero aún no salen de la bodega. Desde aquí se despacha (si necesita transporte) o se entrega directamente.

## Tutoriales

1. **[Crear una reservación](/inventarios/envios/reservaciones/crear-una-reservacion)**: vista de Reservaciones, formulario de creación, edición, impresión, exportación de movimientos y API.
2. **[Reservación de números de serie](/inventarios/envios/reservaciones/reservacion-de-numeros-de-serie)**: ingresar productos identificables desde el proveedor a la bodega seleccionando series específicas.
3. **[Reservación de lotes](/inventarios/envios/reservaciones/reservacion-de-lotes)**: ingresar producto a un lote desde el proveedor con una reservación.

title: "CRM"
sidebar_label: "CRM"
sidebar_position: 0
---

Cuando un cliente potencial llama, escribe o pide una cotización antes de decidirse, cada uno de esos contactos es una oportunidad que no conviene dejar al azar. Este módulo le permite llevar el control y seguimiento de contactos y cotizaciones registrando todas las comunicaciones que se realizan con la persona antes de venderle, para que ningún cliente se pierda en el camino.
